# MITS PCAP Project - IT2A

The Maritime IT Security Research Group (MITS) at NHL Stenden University of Applied Sciences conducts research into cybersecurity within the maritime sector. As part of this research, honeynets are used to collect information about network activity and potential cyber threats. The large amount of data generated by these environments can make manual analysis difficult and time-consuming for security researchers.

For this project, our team will develop a prototype AI-assisted honeynet threat analysis tool to support MITS in analysing this data.

## Description

This project focuses on analysing honeynet data (JSON, PCAP, EVE logs) and identifying suspicious behaviour such as port scanning, repeated failed logins, unusual traffic patterns, and other common attack indicators.
The prototype groups related events into sessions/campaigns, maps behaviour to MITRE ATT&CK techniques, and presents both a **simple overview** and a **technical detailed** view for researchers.

The goal is to make large volumes of honeynet data easier to understand, filter, and investigate.
